# SEO and GEO readiness, Stage 1: technical change report

Date: 2026-10-14. Scope: technical SEO, rendering, performance, structured data, crawlability, accessibility, URLs and hosting. Content work is out of scope.

## Environment found

- Static site generated by `node build.mjs`. The generated HTML is committed at the repository root.
- Hosting is Vercel. The GitHub repo `Jeff07-ux/akiyah-prestige` deploys through the Vercel GitHub app. Production currently serves `akiyah-prestige.vercel.app`. There is no `package.json`, so Vercel runs no build step and serves the committed files as they are.
- Before this stage, Vercel returned a plain-text 404, because `404.html` was never committed. It also sent `Cache-Control: max-age=0` on every asset. It already sends HSTS.

## Files modified or added

- `build.mjs`: responsive image rewriting; hero heading and paragraph visible on first paint; self-hosted font preloads; cache-busting `?v=hash` on assets; structured data graph per page (Organization with logo, WebSite, WebPage/AboutPage/CollectionPage, BreadcrumbList, Service, Article); sitemap `lastmod`; root-absolute URLs in `404.html`; generates `vercel.json`; preview builds without `SITE_URL` are noindex.
- `site.css`: `@font-face` for self-hosted fonts plus metric-matched fallbacks; `img { height: auto }`; larger hit areas on nav, crumb and footer links.
- `motion.js`, `motion.css`: split text keeps its full wording in a visually hidden span instead of `aria-label` on `<p>` (which fixed a Lighthouse ARIA failure).
- New: `tools/optimize-images.mjs`, `img/opt/` (172 WebP variants and `manifest.json`, 31 MB), `img/logo-512.png`, `fonts/` (8 woff2 files, 116 KB), `vercel.json`, `collection/lastmod.json`.
- Regenerated: all HTML pages, `404.html`, `robots.txt`, `sitemap.xml`, `favicon.svg`.

## Remaining technical issues

- `site.css` (about 100 KB) still blocks rendering. Splitting out critical CSS would be an architecture change, so it was left.
- Highly detailed photos (`riad`, `bahia`) stay large at 1600px or wider (about 730 KB as WebP). Smaller widths are served wherever the layout allows.
- Header links point to `./#events` and `./#services`, which are fragments on the home page. This is fine for crawling, but those sections have no URLs of their own.
- Unused image files (`IMG_9832.PNG`, `image.png`, `a_different_perspective-…jpg`, `hero-palms.jpg`) are untracked. Leave them out of the commit.
- `npm install --no-save sharp` is needed only to regenerate image variants. No dependency was added to the site.
